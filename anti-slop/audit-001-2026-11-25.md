## HIGH Priority (Hard Gate)

1. **`R-17`, `R-27`, `R-36` — Misleading `"Verified Staged"` label and hidden error message on failed syncs**
   - Where: `src/scripts/sync.ts` (`L126`, `L279`, `L396`)
   - Reason: Telemetry Ledger hardcodes `"Verified Staged"` in the Integrity column even when `last_status === 'failed'` (`0` records) and hides `last_result.message` (e.g. `"empty payload"`), fabricating a verification signal on failed runs.

2. **`R-17`, `R-36` — `"p50"` badge shown on an arithmetic mean latency metric**
   - Where: `src/components/tabs/ChatLogsTab.astro` (`L61`) vs backend `AVG(latency_ms)`
   - Reason: Labels the all-time average latency (`AVG`) with a hardcoded `p50` (median) badge, misreporting the metric type.

3. **`R-17`, `R-38` — Hardcoded `"5"` count badge on System Prompts shortcut button**
   - Where: `src/components/tabs/ChatLogsTab.astro` (`L28`)
   - Reason: Displays a static number `5` even though `SystemPromptsTab.astro` renders a single combined system prompt viewer rather than 5 separate items.

4. **`R-32` — Keyboard focus outline removed without a visible replacement focus ring**
   - Where: `src/components/tabs/ChatLogsTab.astro`, `SpreadsheetSyncTab.astro`, `ConvertIngestTab.astro`, `CourseListTab.astro`, `ActiveKnowledgeTab.astro`, `SpreadsheetKpiTab.astro`
   - Reason: Multiple inputs, selects, textareas, and toggle switches apply `focus:outline-none` / `peer-focus:outline-none` without `focus-visible:ring-*`, hiding keyboard focus during `Tab` navigation.

5. **`R-25` — Low-contrast `text-gray-400` labels, subtitles, and table headers on white / `bg-gray-50`**
   - Where: `Header.astro` (`L19`), `ChatLogsTab.astro` (`L49, L63, L76, L89, L204, L293, L369, L483`), `SpreadsheetSyncTab.astro` (`L46, L59, L72, L147, L234`), `ActiveKnowledgeTab.astro` (`L21, L36, L51, L65`), `CourseListTab.astro` (`L14, L55, L73`), `SpreadsheetKpiTab.astro` (`L21, L34, L49, L91`), `SystemPromptsTab.astro` (`L34, L48, L65`)
   - Reason: `#9CA3AF` (`text-gray-400`) on `#FFFFFF` yields ~2.54:1 contrast, below WCAG AA 4.5:1 for 10px-12px copy.

6. **`R-39` — Missing accessible names (`aria-label` / `<label>`) on icon-only buttons and filter inputs**
   - Where: `CourseListTab.astro` (`L20-L47`), `ChatLogsTab.astro` (`L168-L187`, `L227-L233`), `SpreadsheetKpiTab.astro` (`L60-L72`, `L115-L121`), `ActiveKnowledgeTab.astro` (`L75-L82`)
   - Reason: Refresh buttons and `‹` / `›` pagination buttons lack `aria-label`, and search/filter controls rely on `placeholder` text instead of accessible labels.

7. **`R-02` — Em dash (`—`) used across UI placeholders and formatters**
   - Where: `SpreadsheetSyncTab.astro` (`L70, L72, L129, L354, L579`), `ChatLogsTab.astro` (`L267, L280`), `CourseListTab.astro` (`L73`), `ThreadModal.astro` (`L9`), `src/scripts/logs.ts`, `src/scripts/kpi.ts`, `src/scripts/utils.ts`
   - Reason: Uses the forbidden em dash character (`—`) for empty states instead of `-` or explicit copy like `Not run yet`.

8. **`R-40` — Logo `<img>` tags missing explicit `width` and `height` attributes**
   - Where: `src/pages/login.astro` (`L51`), `src/pages/pending-access.astro` (`L46`)
   - Reason: `<img src="/amartha.svg" class="h-8 w-auto">` omits intrinsic dimensions, allowing layout shift during image decode.

9. **`R-03` — Sub-44px touch targets on pagination, chart zoom, and icon buttons**
   - Where: `ChatLogsTab.astro` (`L116-L140`, `L227-L233`, `L528-L544`), `SpreadsheetKpiTab.astro` (`L115-L121`), `CourseListTab.astro` (`L38-L47`)
   - Reason: Interactive buttons sized `w-6 h-6` (24px) and `w-8 h-8` (32px) fall below the 44px minimum mobile tap target.
